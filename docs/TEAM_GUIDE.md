# NIAC Live — simple team guide

This guide is written for the person running the event, even if they do not work in technology.

## The three screens

NIAC Live has three different views:

1. **Participant page** — the link or QR code guests open on their phones. They enter a display name, join an activity and answer questions.
2. **Big screen** — the page connected to the projector. It shows the live Nigeria map, questions, correct answers and scores. Open this once and leave it open.
3. **Event control** — the private page used by the host or event operator. Buttons here decide what appears on the big screen.

Think of Event control as the remote control. The Big screen is the television. Participant phones are the game controllers.

## Before people enter the room

1. Connect the presentation computer to the projector.
2. Open the **Big screen** link.
3. Make the browser full screen.
4. On a separate laptop or a second browser window, open **Event control**.
5. Choose **Live Nigeria map**. Confirm the map appears on the projector.
6. Open the participant link on two phones and join with test names.
7. Submit one Lens response and confirm it appears inside the map.
8. Switch Event control to **Passport trivia**.
9. Prepare one question, open answers, answer from both phones, close answers, show the answer and show scores.
10. Turn on **Rehearsal mode** before practising. When practice is finished, use **Clear rehearsal players**, then turn Rehearsal mode off.

Do this full rehearsal using the same internet connection and equipment that will be used during the event.

## How to run Nigeria Through Your Lens

1. In Event control, choose **Live Nigeria map**.
2. The big screen changes to the Nigeria map automatically.
3. Ask participants to scan the QR code or open the participant link.
4. Participants submit a positive word or short phrase.
5. Their response goes live immediately.
6. If a response should not be shown, open **Manage words on the live map** and press **Hide**.
7. If a response has an obvious spelling mistake, press **Fix spelling**, correct it and save.

You do not need to approve each normal response. Moderation is only for correcting or hiding something.

## How to run Passport trivia

Use this same order for every question:

1. Choose **Passport trivia** under “Choose what appears on the big screen”.
2. Choose a question from the list.
3. Press **Prepare question**. This gets the question ready but does not open it to players.
4. When the host has finished reading or introducing it, press **Open answers**. The countdown starts immediately.
5. Watch the “Answers received” number.
6. When time is up, press **Close answers**. Late answers are rejected.
7. Press **Show the answer**. The correct option and explanation appear.
8. Press **Show scores** when the host wants the leaderboard.
9. Choose another question and repeat.

Scores from Passport trivia continue across both event days. A returning participant uses their recovery code to restore their profile on another device.

## How to run Decode the State

1. Choose **Decode the State**.
2. Choose the state round and press **Prepare question**.
3. Press **Open answers** to show the first clue and accept answers.
4. If the state has not been guessed, press **Show next clue**.
5. After the final answer window, press **Close answers**.
6. Press **Show the answer**, then **Show scores**.

Earlier correct answers are worth more than answers submitted after later clues. Decode scores are separate from Passport scores.

## What every screen status means

- **Welcome screen** — no question is active. It is safe to choose what comes next.
- **Question ready** — the next question is prepared but players cannot answer yet.
- **Answers are open** — the timer is running and players can submit one answer.
- **Answers are closed** — no more answers are accepted.
- **Answer is showing** — the correct option and explanation are visible.
- **Scores are showing** — the leaderboard is on the projector.
- **Paused** — the event has stopped safely. Existing answers remain saved.
- **Event ended** — the session is closed until it is returned to the welcome screen.

## Editing a question

1. Open **Edit questions** from Event control.
2. Search for the question by a word or category.
3. Press **Edit question**.
4. Change the question wording or any of the four answer options.
5. Select the circle beside the correct answer.
6. Set the answer time. Twenty seconds is a sensible default.
7. Write the short explanation shown after the answer is revealed.
8. Add the source used to check the fact.
9. Set the review status:
   - **Needs fact check** — still being researched and unavailable in the live question list.
   - **Reviewed** — checked by a team member but not yet final.
   - **Ready to use** — approved and available to the event operator.
10. Press **Save question**.

A question cannot be edited while it is actively accepting answers or being revealed. Finish it or return to the welcome screen first. This protects the score from changing halfway through a question.

## If something goes wrong

### The operator is unsure what to press

Press **Pause everything**. This keeps answers and scores safe. Check the big screen, then return to the welcome screen or continue.

### The big screen shows the wrong activity

In Event control, choose the correct activity. The projector should switch automatically within a few seconds. Do not open several projector tabs.

### Someone cannot join

Ask them to refresh the participant page and try a short display name. If they joined earlier on another device, use **Returning on another device?** and their recovery code.

### A response on the map is unsuitable

Open **Manage words on the live map** and press **Hide** beside it. The public map only displays approved, visible responses.

### The wrong answer was configured

If the question is already live, close answers and use **Void current question**. This removes its points from every score. Correct the question in Edit questions before using it again.

### Internet briefly disconnects

Do not reset anything. Wait for the connection to return. Participant answers that were confirmed remain saved. The participant screen will show that it is reconnecting.

## Tools that require extra care

- **Void current question** recalculates scores without that question.
- **Clear rehearsal players** removes practice participants and practice answers.
- **Reset live event data** removes real participant event data and should only be used by the lead administrator.
- **End event** closes the current event session but does not erase data.

When in doubt, pause. Never reset the live event as a troubleshooting step.

## One-minute explanation for a nontechnical stakeholder

“Guests join NIAC Live from their phones using a link or QR code. Their phones send answers to a central online database. The event operator uses a private control screen to choose what the projector displays. During Nigeria Through Your Lens, submitted words appear inside a live Nigeria map. During trivia, the operator prepares a question, opens and closes answering, reveals the correct answer and shows the leaderboard. The system saves confirmed answers and calculates scores centrally, so refreshing a phone does not change the official result.”

## Final event-day checklist

- Big screen link open and full screen
- Event control open on a separate device or window
- Participant QR code tested from a phone
- Live Nigeria map tested with one response
- One complete trivia question rehearsed
- Questions marked Ready to use
- Rehearsal participants cleared
- Rehearsal mode turned off
- Host and operator agree on the button sequence
- Backup operator has this guide
